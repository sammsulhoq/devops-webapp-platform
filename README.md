# DevOps Web Application Platform

An end-to-end DevOps capstone demonstrating automated infrastructure provisioning, configuration management, application delivery, and monitoring on AWS.

Built as part of the Hero Vired DevOps Capstone.

## Project Status

Initial setup in progress. Infrastructure and deployment are not yet implemented.

## Planned Technology Stack

| Area | Technology |
|---|---|
| Web application | Python, Flask |
| Containerization | Docker |
| Infrastructure as Code | Terraform |
| Configuration management | Ansible |
| CI/CD | Jenkins |
| Container registry | Amazon ECR |
| Container orchestration | Amazon EKS |
| Monitoring | Prometheus, Grafana |

## Project Goals

- Provision reproducible AWS infrastructure.
- Configure automation servers with Ansible.
- Test, build, and deploy the application through Jenkins.
- Run the application on Kubernetes with health checks and scaling.
- Monitor application and infrastructure health.
- Document validation, cost decisions, and cleanup.
